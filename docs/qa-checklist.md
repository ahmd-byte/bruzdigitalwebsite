# QA checklist

## Design review
- [ ] Approved palette values and tagline are used exactly.
- [ ] Typography proposal is compared at desktop and mobile widths.
- [ ] Heading and body text remain easy to distinguish and read.
- [ ] Contrast is checked for text, buttons, focus indicators, hover, and disabled states.
- [ ] Orange remains a limited accent.
- [ ] Product visuals are labelled accurately as product UI illustrations.
- [ ] The existing System Lab motion has a clear start and settled state.
- [ ] The mobile layout preserves hierarchy and contact actions.

## Implementation and validation — later phase
- [ ] Preserve semantic landmarks, anchor links, keyboard order, and visible focus.
- [ ] Respect reduced-motion preferences.
- [ ] Check all navigation and contact form states.
- [ ] Run the production build and audit scripts.
- [ ] Validate desktop and mobile in a browser.
- [ ] Run Lighthouse and record actual scores; do not claim results without them.
