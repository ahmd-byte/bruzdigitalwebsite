# Bruz Digital revamp

The five main pages are static HTML generated by `python tools/build_revamp_pages.py`. Edit page content in that script, then regenerate. The visual system is in `revamp.css`; mobile navigation is in `revamp.js`. Older `/services/*.html` routes redirect to the consolidated Studio page.

## Approved visual direction

- The site uses a restrained Highbeam × Engineering Lab system: charcoal and near-black surfaces, cool slate panels and borders, white type, and one lime signal color.
- The homepage keeps the 52/48 editorial split. Its System Lab sequence reveals the architecture, connects the nodes, transforms into Bruz product UI, and settles after one run. It does not autoplay in a loop.
- Section changes come from depth and border rhythm within the same dark family rather than unrelated light color blocks.

## Content and asset audit

- The existing site used a BRUZ wordmark and acid-yellow accent. The revamp keeps both. No separate verified Bruz logo file was present in this checkout.
- The Highbeam material at `../bruzclone/examples/highbeam-design` was used for layout and editorial rhythm reference only. No Highbeam copy or media was imported.
- The previous main pages contained fictional projects, people, numbers, quotes and a Toronto location. These have been removed from the live pages.
- The Johor Plantations Hackathon 2026 result, AI Quality Control Tower name, and the team names Sarvind Raj and Nabilah Abas came from the approved brief and later name confirmation. The case-study interface is explicitly marked as an illustration, not a deployed screenshot.
- The user supplied and identified the verified portraits for Sarvind Raj and Nabilah Abas. They are stored under `assets/team/` and used on the homepage and team page.
- Bruz OCR's local README confirms document ingestion and image-quality assessment today. OCR, review and export remain planned stages; the site reflects that. Bruz Intelligent is described as in development.
- `hello@bruzdigital.com` is the confirmed contact address and is used in the footer, contact page, and project brief mail link.
- Product previews use clearly labelled interface illustrations because no verified Quality Control Tower, Bruz Intelligent, or Bruz OCR product screenshots were supplied. They describe only confirmed capabilities and statuses.
- Plus Jakarta Sans is served from the repository, so the main pages do not rely on a third-party font request.

## Local preview

Run `python -m http.server 8765` from the repository root, then open `http://localhost:8765/index.html`.

## Production build

- Run `python tools/build_production.py` to create the deployment-only `dist/` directory.
- Run `python tools/audit_production.py` before every preview or production deployment.
- Netlify configuration lives in `netlify.toml`. It adds the hosted project brief form, security headers, long-lived asset caching and redirects for legacy service routes.
- The deployment package includes canonical URLs, organization structured data, `robots.txt`, `sitemap.xml`, the social sharing card, a privacy page, a confirmation page and a branded 404 page.
- Publishing instructions and the rollback checklist are in `DEPLOYMENT.md`.
